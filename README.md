
# Sistema de Otimização Fotovoltaica com Algoritmo Genético

## Objetivo
Este projeto implementa um MVP acadêmico de um algoritmo genético aplicado
ao dimensionamento de sistemas fotovoltaicos residenciais.

## Foco Acadêmico
- Algoritmos Genéticos
- Otimização Heurística
- Simulação Computacional
- Convergência Evolutiva
- Modelagem Computacional

## Estrutura

src/
├── core/
├── genetic/
├── simulation/
├── visualization/
├── data/
└── utils/

## Como executar

```bash
pip install -r requirements.txt
python src/main.py
```

## Funcionalidades
- População evolutiva
- Fitness customizado
- Múltiplos cenários
- Histórico de gerações
- Gráficos de convergência
- Salvamento de resultados
- Reprodutibilidade por seed
